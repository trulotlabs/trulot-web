# LaMesaADU front door V0

Packet 68 adds a bounded, non-production homeowner front door over the shared TruLot La Mesa engine. The route is available only when `TRULOT_LA_MESA_ADU_PREVIEW=1` in development or test, carries noindex metadata, and is absent from the sitemap.

The preview resolves only sealed Packet 67 benchmark records plus clearly labeled ambiguity test fixtures. Homeowner answers remain `USER_PROVIDED`, are held in component memory, and are passed to the shared evaluator. No lead is sent or persisted.
