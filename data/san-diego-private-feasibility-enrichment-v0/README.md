# San Diego private feasibility enrichment v0

Private, authenticated-server evidence for Packet 101. It consumes only normalized Packet 100 DTOs and makes no public, legal, compliance, occupancy, or exact-unit-count conclusion. The benchmark joins zoning/Coastal labels only as coverage dimensions; mapped context never establishes eligibility.

## Existing private V4 path

The existing feasibility contract combines parcel truth, zoning/profile context, and project/homeowner answers into bounded result states. Before this packet, San Diego had no server adapter that supplied Packet 100 dwelling/currentness/question facts, so property questions remained generic. `lib/private-feasibility-enrichment.ts` is the injection seam: it accepts the normalized DTO after authenticated lookup, never recomputes raw-source semantics, and leaves the prior V4 evidence flow available on lookup failure.

## Persistence and outcomes

Recorded facts remain immutable Packet 100 evidence. Homeowner corrections remain `USER_PROVIDED` user/org state, while uploaded plans and project outcomes remain project-scoped. Later confirmations or permit updates can inform a new private judgment without mutating historical source evidence.
