# La Mesa permit intelligence v0

Packet 74 is a bounded, local-only reconnaissance artifact from 50 stratified La Mesa parcel/address searches against the official public MaintStar portal on 2026-10-27. It preserves permit evidence as a separate authority class. It is not a citywide dataset, population estimate, legal-status determination, current unit count, or authorization for public redisplay.

The result is **RECON ONLY** because automation/reuse terms are not published, the endpoint returned an undocumented 429 throttle, source APNs are absent, and completeness requires explicit pagination. The current safe path is manual/operator verification. The long-term path is a City-provided export/API with written reuse terms.

The normalized artifact intentionally retains the portal's public raw fields inside each evidence record for auditability. No owner, applicant, account, credential, token, cookie, or private environment value is included.
