# LaMesaADU protected private-pilot operating plan

Start with 3–5 participants and 5–10 real La Mesa parcels. Include at least two homeowners plus internal/operator sessions. Ask each participant to find one known parcel, understand the first result, answer only the facts they know, review one pathway result, open the evidence disclosure, and identify the next step they would take.

Capture only whether they found the parcel, understood the result, encountered a confusing question, trusted the sources, knew the next step, and would request professional help. Record short factual notes using `pilot-observation-template.md`; do not create an elaborate survey.

Run the pilot on an access-protected preview with the private-preview flag enabled. Do not use a production domain, public indexing, production lookup data, live lead delivery, session replay, or behavioral tracking.
