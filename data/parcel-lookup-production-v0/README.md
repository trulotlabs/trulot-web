# Parcel Lookup Production V0 evidence

`acquisition-identity-reconciliation.md` records the Packet 46A decision that
the Parcel V2 acquisition identifier is an exact, case-sensitive identity and
documents the immutable evidence for its canonical literal.

`rehearsal.json` is the Packet 44 disposable SQLite design evidence.
`postgres-rehearsal.json` is regenerated by
`node scripts/parcel-lookup-production-v0/postgres-rehearsal.mjs`. It applies
the Packet 45 migration to a disposable PostgreSQL/PostGIS database containing
all 393,733 accepted City of San Diego identities, rejects a deliberately
mismatched source seal, verifies correctness, grants, query plans, and warm
latency, and never connects to Supabase or a production system.

`browser-result.json` and `screenshots/` contain the actual local Next.js API +
PostgREST + full-city PostgreSQL browser evidence. `feature-flag-off.json`
records page/API 404 containment. `rollback-rehearsal.json` records removal of
lookup-only objects while preserving Parcel Base V2 and its acquisition/run
metadata. These are local engineering measurements, not production-network or
public-service claims.
