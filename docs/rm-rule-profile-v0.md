# RM Rule Profile V0

Packet 51 defines a reusable, versioned rule layer for multifamily residential base zones, beginning with RM-2-5. It keeps base-zone table cells, measurement definitions, footnotes, external program modifiers, and project facts separate. The artifacts do not evaluate a project, calculate capacity, or affect production.

The application-time profile selects O-21618 for 2024-01-29 outside Coastal and preserves the pre-O-21836 FAR-definition boundary. The current profile uses the separately pinned July 2026 compiled Code. Table 131-04G cells carry their raw values and footnote references; footnotes apply only after their predicates are supported.

Height uses §113.0270 plumb-line and overall-height semantics plus RM-2-5 footnotes 18 and 37. FAR uses Code-compatible gross floor area divided by total premises area, with required-dedication and multiple-zone treatment preserved by legal version. An APN, assessor area, GIS area, or plan label does not establish a legal premises denominator by itself.

The Packet 50 replay remains unresolved by design. Its height label lacks the grade, top-point, structure, roof, and angled-plane evidence required for a Code comparison. Its FAR inputs lack a component-level §113.0234 numerator reconciliation and a legally established premises denominator. The rule profile therefore closes reusable semantics while retaining fail-closed project evidence gates.

The profile is ready for bounded use. The next feasibility step is to close Packet 50 FAR evidence because Code-compatible GFA and premises area remove the broadest remaining numerator and denominator uncertainty.
