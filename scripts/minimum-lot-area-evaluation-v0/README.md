# Minimum Lot Area Evaluation V0 — Packet 27

Run `python3 scripts/minimum-lot-area-evaluation-v0/build.py` and `python3 scripts/minimum-lot-area-evaluation-v0/test.py` from the repository root. The evaluator is sealed to APN `6341302200` and the `minimum_lot_area` rule family. It reads existing repository evidence, evaluates one deterministic comparison, and cannot calculate overall zoning compliance, capacity, or another rule family.
