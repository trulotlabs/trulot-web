# Approved Plan Golden Corpus V0

This Packet 41 builder creates a deterministic internal validation corpus from operator-owned or authorized plan sets. Source PDFs remain outside Git. Repository artifacts contain only source paths and hashes, bounded non-sensitive facts, provenance, comparison states, compatibility findings, tests, and documentation.

Run:

```bash
python3 scripts/approved-plan-golden-corpus-v0/build.py
python3 scripts/approved-plan-golden-corpus-v0/test.py
```

The corpus is single-property and three-project. It proves the evidence contract and privacy controls; it is not a representative sample of San Diego projects and does not establish parcel compliance or capacity.
