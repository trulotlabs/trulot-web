# Minimum Lot Depth Evaluation V0 — Packet 28

Run `python3 scripts/minimum-lot-depth-evaluation-v0/build.py` and `python3 scripts/minimum-lot-depth-evaluation-v0/test.py` from the repository root. The evaluator is sealed to APN `6341302200` and the `minimum_lot_depth` rule family. It reconstructs the SDMC midpoint-to-midpoint depth from recorded-map geometry and cannot evaluate width, frontage, setbacks, overall zoning compliance, or development capacity.
